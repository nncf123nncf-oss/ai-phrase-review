# AIっぽい言い回しの見直し

ChatGPTやClaudeに書かせたお知らせ・投稿・お礼の文を貼ると、AIの文によく出ると言われる言い回しに番号つきの印が付き、言い換えの候補が出るページです。候補を押すと「直した文」に反映され、コピーして使えます。

- **AIが書いたかどうかは判定しません。** 人が書いた文にも同じ言い回しは出ます
- 印が付いた言い回しは間違いではありません。自分の言い方なら、そのままで
- 言い換えは決まった候補を差し込むだけです。前後のつながりがおかしくなったら、直した文の欄で手で直してください
- 貼った文は保存も送信もしません（ページを閉じれば消えます）。閲覧数を数えるアクセス解析（Cloudflare Web Analytics）だけが入っています
- このページ自体はAIを使っていません

## 拾うもの

- 締めの決まり文句（いかがでしたか・〜てみてはいかがでしょうか・ぜひお気軽に・心よりお待ちしております など）
- 言い切り・まとめの型（と言えるでしょう・ではないでしょうか・〜ことが重要です・活用 など）
- ぼやけた飾り言葉（さまざまな・至福のひととき・魅力・演出・まさに など）
- かたすぎる丁寧さ（させていただきます・でございますは2回目から、となっております など）
- 見た目の癖（Markdown記号の消し忘れ・長いダッシュ・「！」5個以上・同じ文末の4文以上の連続・【】の見出し3つ以上）

一覧は固定です。追加・編集はできません。英語の文は対象外です。

## 使い方

1. 「① 文を貼る」に文を貼る（5,000字まで）。「見本の文を入れる」で架空のお知らせを試せます
2. 「② 印のついた文」と「③ 見直し候補と言い換え」を見て、候補（→ 言い換え／削る／このまま）を押す
3. 「④ 直した文」を確かめ、「直した文をコピー」

## 開発用

- `node source/core-test.js` — 言い回しの拾い方・言い換えの差し込みの検算
- `node source/check.js <出力フォルダ>` — Chrome headless での実画面の確認
- `node source/shoot.js <出力フォルダ>` — 投稿用スクリーンショットの撮影

HTML1枚・外部ライブラリなし。
